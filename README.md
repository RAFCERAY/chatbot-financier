## Overview

FIN.BOT SG is a Gen AI financial assistant that automates the generation of banking reports on OTC (over-the-counter) derivatives. Built during the **Société Générale Datathon 2024**, it lets analysts query derivative data in natural language and get structured reports and visualizations in return.

**FR** — FIN.BOT SG est un assistant financier Gen AI qui automatise la génération de rapports bancaires sur les dérivés OTC. Développé lors du **Datathon Société Générale 2024**, il permet d'interroger les données de dérivés en langage naturel et d'obtenir rapports structurés et visualisations.

## Features

- 💬 **Natural language queries** on OTC derivatives data / *requêtes en langage naturel*
- 📊 **Automated report generation** with charts / *génération automatique de rapports*
- 🏦 **Banking domain NLP** tuned for financial terminology / *NLP adapté au vocabulaire financier*
